# koishi-plugin-sticker-convert-br

## 项目介绍 (Project Introduction)

### 中文
本插件基于原版 koishi-plugin-sticker-convert 而来，**移除了群相册功能**，并且修复了GIF转发问题，其余功能完全兼容原版

> 原版 koishi-plugin-sticker-convert 基础功能文档：https://github.com/WhiteBr1ck/koishi-plugin-sticker-convert   

### English
This plugin is based on the original koishi-plugin-sticker-convert, **removing the group album function** and fixing the GIF forwarding issue. All other functions are fully compatible with the original.

> Original koishi-plugin-sticker-convert basic function documentation: https://github.com/WhiteBr1ck/koishi-plugin-sticker-convert
